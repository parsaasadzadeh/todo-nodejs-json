
A clean, professional, and lightweight Todo application built with Node.js, Express, and EJS. This project demonstrates a solid understanding of backend fundamentals by utilizing a local JSON file as a database via the File System (`fs.promises`) API, perfectly structured around the MVC (Model-View-Controller) architecture.

## Features
* **Task Management:** Add new tasks, mark them as completed, and delete them.
* **Dynamic UI:** Tasks dynamically update their visual state (strikethrough and opacity changes) upon completion.
* **Statistics:** Displays real-time calculations of total tasks and completed tasks.
* **MVC Architecture:** Clean separation of concerns between Models, Views, and Controllers.
* **RESTful Routes:** Form actions utilize appropriate HTTP methods (POST for state changes) for better web standards.

## Tech Stack
* **Backend:** Node.js, Express.js
* **Template Engine:** EJS
* **Database:** File System (Local JSON file via `fs.promises`)
* **Styling:** Tailwind CSS (via CDN in EJS layouts)

اپلیکیشن مدیریت وظایف
یک اپلیکیشن حرفه‌ای، سبک و مدرن برای مدیریت وظایف (Todo) که با Node.js، فریم‌ورک Express و موتور قالب‌ساز EJS توسعه داده شده است. این پروژه به جای استفاده از دیتابیس‌های سنگین، از یک فایل JSON محلی (از طریق ماژول fs.promises) به عنوان دیتابیس استفاده می‌کند تا درک عمیق از معماری MVC (مدل-ویو-کنترلر) و مدیریت فایل‌ها در سرور را به نمایش بگذارد.

ویژگی‌های پروژه
مدیریت تسک‌ها: امکان افزودن، حذف و تغییر وضعیت تسک‌ها به "انجام شده".

رابط کاربری پویا: تغییر ظاهر تسک‌ها (خط خوردن متن و تغییر رنگ) بلافاصله پس از تکمیل.

آمار دقیق: محاسبه و نمایش لحظه‌ای تعداد کل تسک‌ها و تسک‌های انجام شده در بالای صفحه.

معماری MVC: جداسازی اصولی منطق برنامه (Controllers)، ساختار داده (Models) و رابط کاربری (Views).

روت‌های استاندارد: استفاده از متد POST برای عملیات حساس (حذف و تغییر وضعیت) بر اساس استانداردهای وب.

بک‌اند: Node.js, Express.js
